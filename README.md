## 🚀 주요 기능

가천대학교 및 인천대학교 학생들의 편리한 학습 관리를 위해 강력한 기능들을 제공합니다.

1. **녹화강의 완벽 지원**
   - 녹화강의의 **마감 기한**과 **학습 진행도(%)**를 실시간으로 확인하고 바로 시청 페이지로 이동할 수 있어요.
2. **퀴즈 현황 추적**
   - **형성평가 및 퀴즈**의 제출 여부와 마감 기한도 대시보드에서 함께 관리할 수 있어요.
3. **실시간 마감 카운트다운**
   - 서버 갱신 없이도 **분 단위로 줄어드는 남은 시간**을 실시간으로 확인할 수 있어요.
4. **강력한 멀티 필터링**
   - 상태(진행 중, 마감 임박 등), 카테고리, 과목별로 원하는 정보만 골라볼 수 있어요.
5. **어디서나 접근 가능**
   - 사이버캠퍼스뿐만 아니라 **모든 웹사이트**에서 대시보드를 열어 마감 기한을 체크할 수 있어요.
6. **최적화된 UI/UX**
   - 한국어 과목명 자동 정제, 부드러운 애니메이션, 가독성이 개선된 로딩 진행 바를 제공해요.

## 🤔 프로젝트 소개

사이버캠퍼스의 파편화된 정보를 한 곳에서 모아보고 싶다는 니즈를 충족하기 위해, 기존의 도구들을 계승하고 현대적인 환경(녹화강의, 퀴즈 등)에 맞춰 완전히 새롭게 리빌딩된 프로젝트입니다.

## 📝 이용 방법

1. **설치**: 확장 프로그램을 브라우저에 추가합니다.
2. **접근**: 사이버캠퍼스 로그인 후, 우측 하단 아이콘을 클릭하거나 단축키(`Ctrl + /` 또는 `Cmd + /`)를 누르세요.
3. **동기화**: 갱신 버튼을 눌러 최신 과제 정보를 가져옵니다.

## 학교별 개발

학교별 빌드는 `npm run build:gachon`, `npm run build:incheon`으로 실행하며, 결과물은 각각 `dist/gachon`, `dist/incheon`에 생성됩니다.

- `src/services/parser/gachon/`: 가천대 LMS 수집, HTML 선택자, 제출 판정, 로그인 확인, 활동 이동 주소
- `src/services/parser/incheon/`: 개편된 인천대 LMS(`lms.inu.ac.kr`)의 메인·섹션·상세 페이지 수집 및 상태 판정
- `src/services/parser/index.ts`: 빌드 대상 학교의 구현을 선택하는 공통 진입점
- `src/services/parser/types.ts`: 학교별 구현이 제공해야 하는 공통 인터페이스
- `src/services/parser/activities.ts`: 수집 결과를 화면용 데이터로 변환하는 공통 코드

대시보드·필터·저장소는 공유합니다. 학교별 LMS 주소와 확장 프로그램 정보는 `.env.gachon`, `.env.incheon`에서 관리합니다.

인천대는 메인의 목록형·카드형에서 교과과목을 추출하고, 과목별로 `mode=sections`를 지정해 섹션을 한 번씩 조회합니다. 기본 과목 주소는 대시보드를 반환할 수 있으므로 수집에 사용하지 않습니다. 과제·퀴즈는 화면의 완료·미완료 태그가 없을 때만 상세 조회합니다. 영상은 기간 없이 영상 길이만 표시되면 출석 체크 없음으로 판정합니다. 출석 체크 없음·완료·시작 전 영상은 상세 조회를 생략하고, 나머지는 상세 페이지에서 실제 진도율과 출석 상태를 확인합니다. 요청은 동시 3개로 제한합니다.

동기화 중에는 저장된 결과를 먼저 표시하고 과목별로 갱신합니다. 조회 실패 시 이전 결과가 있으면 유지하고 실패 표시를 남기며, 이전 정보도 없으면 완료 여부를 확인 불가로 표시합니다.

검증은 `npm test -- --run`으로 실행합니다. `samples/incheon/`에 실제 HTML이 있으면 샘플 검증도 함께 실행하며, 이 HTML 파일은 Git에서 제외합니다.
